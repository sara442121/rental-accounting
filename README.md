# سیستم جامع حسابداری ابزارآلات (نسخه دسکتاپ و وب)

این پروژه شامل دو نسخه **دسکتاپ (Tkinter)** و **تحت وب (Flask)** برای مدیریت حسابداری اجاره ابزارآلات است.

## ساختار پروژه:
- `desktop/`: حاوی کد اصلی نسخه دسکتاپ (`main.py`).
- `web/`: حاوی کد نسخه تحت وب و قالب‌های HTML.
- `install_and_run.bat`: اسکریپت نصب خودکار و اجرا برای ویندوز.
- `requirements.txt`: لیست کتابخانه‌های مورد نیاز.

## امکانات جدید:
- **نسخه دسکتاپ حرفه‌ای:** رابط کاربری جدید با قابلیت ثبت عکس کارت ملی و مدیریت پیشرفته.
- **نسخه وب (آزمایشی):** پیاده‌سازی شده با Flask برای مشاهده داشبورد در مرورگر.
- **قابلیت ساخت فایل اجرایی:** آماده‌سازی شده برای تبدیل به `.exe` با استفاده از PyInstaller.

## نحوه اجرا در ویندوز:
فقط کافیست فایل `install_and_run.bat` را اجرا کنید. این اسکریپت به طور خودکار:
1. کتابخانه‌های لازم را نصب می‌کند.
2. فایل اجرایی را می‌سازد.
3. برنامه را اجرا می‌کند.

## اجرای دستی نسخه وب:
```bash
cd web
python app.py
```
سپس در مرورگر به آدرس `http://127.0.0.1:5000` بروید.

## اجرای دستی نسخه دسکتاپ:
```bash
cd desktop
python main.py
```

## پیش‌نیازها:
```bash
pip install flask pyinstaller
```

# سیستم حسابداری اجاره کالا و ابزار

این یک نرم‌افزار حسابداری کامل برای مدیریت اجاره کالا، ابزار و تجهیزات است که با استفاده از Python و Tkinter توسعه یافته است.

## امکانات سیستم:
- **مدیریت کالاها:** ثبت کالا با نرخ‌های اجاره متنوع (دقیقه‌ای، ساعتی، روزانه، هفتگی و ماهانه).
- **مدیریت مشتریان:** ثبت و نگهداری اطلاعات مشتریان.
- **ثبت اجاره:** محاسبه خودکار زمان پایان و مبلغ اجاره.
- **برگشت کالا:** محاسبه خودکار جریمه دیرکرد و صدور فاکتور.
- **مدیریت فاکتورها و پرداخت‌ها:** پیگیری وضعیت پرداخت فاکتورها.
- **خروجی گزارشات:** امکان خروجی گرفتن به صورت PDF و Excel.
- **پایگاه داده داخلی:** استفاده از SQLite برای ذخیره امن اطلاعات.

## پیش‌نیازها:
برای اجرای برنامه باید پایتون نصب باشد و کتابخانه‌های زیر را نصب کنید:

```bash
pip install reportlab openpyxl
```

## نحوه اجرا:
فایل اصلی برنامه را اجرا کنید:

```bash
python rental_app.py
```

## ساختار پروژه:
- `rental_app.py`: فایل اصلی کد برنامه.
- `requirements.txt`: لیست کتابخانه‌های مورد نیاز.
- `rental_accounting.db`: پایگاه داده برنامه (پس از اولین اجرا ساخته می‌شود).
